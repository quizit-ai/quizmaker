1. Service account

How do I get this?
  1. In Google Cloud Console, create/select a project and enable the Google Sheets API.
  2. IAM & Admin → Service Accounts → create one → Keys → Add key → JSON and download it.
  3. Open the JSON file, copy everything and paste it below.

2. Google Sheet

Create a Google Sheet, click Share, and give the service account email Editor access.

What gets saved

After submitting a quiz, the participant can press Save to Google Sheet. One row is added to the configured tab (created if missing) with these columns: Timestamp, Name, Email, Score, Question 1, Answer 1, Question 2, Answer 2 … The tab grows automatically for longer quizzes.
